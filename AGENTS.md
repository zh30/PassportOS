# PassportOS — agent notes

- Stack: Rust `no_std` + `esp-hal` 1.2 (git tag `esp-hal-v1.2.0-rc.0`) + embassy via `esp-rtos`.
- Host-testable logic is **only** in `crates/passport-core`. Do not put HAL types there.
- ADC millivolt windows are official `{[0,150),[150,447),[447,1900)}`. Tests must call `decode_millivolts` / `ButtonDecoder::feed` / `Shell`, not a copy.
- Input: `INPUT_TICK_MS=5`, press debounce 30 ms, **release debounce 5 ms**. Sample ADC after SPI. Do not feed the decoder a copied millivolt window. Live game paint is `FRAME_TICK_MS=20` via `cadence_redraw` — never `request_live` on the 5 ms sample. No `[btn]` USB print on the ADC path. While Flap/Stack/Brick/Boo/Tune is focused, UP/DOWN click and long-press stay with the app (release-click must not hop tiles; paddle hold must not switch workspaces). Long OK is still home. Launcher home is three islands (Play / Tools / System), not an 8-row dump. Island focus moves must repaint 88px island cards (`desktop`), never 44px `launcher_cards` rows. UP on the first app of a group, or Long OK in a group, zooms back to islands — do not close the launcher onto an empty desk. Island/group copy is ASCII 32..126 only (`draw_text` walks bytes — no UTF-8 middots). Captions must fit `island_blurb_cols()`; firmware paints with `draw_text_fit`.
- Mic is system input: firmware `pcm16_le_level` → `Shell::tick_mic` → `AppLifecycle::Mic` / `App::on_mic`. Opt in with `set_wants_mic`. Tests drive `tick_mic` / `MicGate`, not I2S. I2S starts only while `shell.mic_listen()`. ES8311 init lives in `passport-core::es8311::INIT` (ADC clocks on `0x01=0x3F`); firmware only writes the table. Pitch: `feed_pcm` → AMDF Hz for Tune (guitar / ukulele / violin).
- One I2C0, one ADC1. Never construct a second bus/unit for scans.
- Wi-Fi, BLE, and large audio DMA are exclusive (`ExclusiveManager`). Firmware enforces it too: `WifiScan`/`WifiConnect` stop BLE (`BLE_CMD`), `BleAdvertise` drops Wi-Fi (`WIFI_CMD::Disconnect` + `wifi.disconnect()` clears the joined mark without a rejoin evt).
- I2S mic: RX has only DIN — `sig_loopback` (`I2S_RX_LOOPBACK_TX=true`) slaves RX onto the TX clock domain, so TX must stay fed (silence or PCM) or shared BCLK/WS stall. 500 ms RX watchdog restarts the DMA read; pitch picks the louder stereo channel (`push_pcm16_le_auto`), never a hardcoded side.
- Audio: `StatusBar::volume` 0..=100 + `muted` → ES8311 DAC reg `0x32` via `es8311::dac_volume` / `codec::es8311_set_volume`. `audio beep` is bounded (`BEEP_MS` deadline in the UI loop, not a task). `audio stop` halts TX/RX DMA when the mic doesn't own I2S.
- System Wi-Fi: overlay + 3-key IME live in `passport-core`. Firmware `wifi_worker` keeps `WIFI` (scan then `connect_async`). Never await radio on the UI task. `SideEffect` is `Copy`; SSID/pass stay on `Shell`. After `Connected` the worker parks on `wait_for_disconnect_async` racing `WIFI_CMD` — drops surface as `WifiEvt::Disconnected` → `apply_wifi_drop` (bounded open-network rejoin, `REJOIN_MAX=3`); a user Disconnect does **not** emit Disconnected. Controller buffers are trimmed (`static_rx=4 dyn_rx=16 dyn_tx=8 ampdu off`) — defaults nearly exhaust the 72 KB heap; `WifiController::new` consumes the peripheral on failure, so the dead-init path still answers commands with `Failed(Radio)`.
- BLE: connectable advertising + GATT Battery service (`ble_task`, `trouble-host` `#[gatt_server]`). `BleCmd::Start/Stop` over `BLE_CMD`, conn events over `BLE_EVT` → `status.ble_conn` (`BT*` on screen). `radio off` stops advertising; `BLE_UP` (portable_atomic — no CAS on rv32imc, load/store only) tracks session liveness. **`BleServer::new_with_config` is once-per-process** — trouble-host's `PeripheralConfig::build` and large-characteristic storage live in `static_cell::StaticCell`s, so a second call panics in `StaticCell::init`. The server lives in `BLE_SERVER: OnceLock`, built on first session and reused across all later swaps. Teardown timeouts are a wedged-worker state: keep the `*_task_up` flag and abort the opposite radio start — never allocate a stack over possibly-held buffers.
- Flash factory app at `0x10000` (3 MB). Do not erase `cardid@0x356000` or `recovery@0x700000`. KV high-score page is `0x350000` (4 KB, between factory and cardid). Wi-Fi creds persist as a `POSW` record at page offset 32 (`wifi.ssid`/`wifi.pass`/`wifi.open`); `KvStore` batches wifi writes (`wifi_dirty` → `flush()`) — one erase+write per commit, and `wifi_commit_saved` runs only after a successful join.
- USB console is GPIO18/19 Serial/JTAG. UART0 TX is GPIO21 (backlight) — never enable it. **Never `usb_tx.write_all().await` bare** — JTAG TX only drains while a host app holds the port; standalone the await never returns and freezes the whole UI loop. Route every console echo through `usb_echo!` (60 ms `with_timeout`, drop on absent reader). `println!` is safe: esp-println has its own `TIMED_OUT` bailout for exactly this case.
- Unplugged idle standby (30 s, `IDLE_STANDBY_MS`) is `SideEffect::SetBrightness(0)` then restore; not `SleepLight` / `SleepDeep`. Wake keys are swallowed. Keep the 5 ms ADC loop while blanked; skip live SPI paints.

- NTAG213 is a passive tag (no MCU bus). Firmware exposes NDEF encode + Tap app; `mcu_read`/`mcu_write` are `NoBus`. Power button is not a GPIO.
- Perf decisions (measured): `opt-level = "s"` beats `z`/`3` on flash size + speed; `force-frame-pointers` removed (re-add in `.cargo/config.toml` when debugging panics); display SPI at 80 MHz; I2C at 400 kHz (codec/battery both support fast mode); `ESP_HAL_CONFIG_PLACE_SPI_MASTER_DRIVER_IN_RAM` keeps SPI code off XIP and safe across KV flash writes; **this board's flash is DIO-only** — `--flash-mode qio` boot-loops (TG0WDT before app entry) at any freq, runner pins `dio/40mhz`. Display SPI needs `ClockSource::Pll80m` to reach 80 MHz (default Xtal caps at 40 MHz → `FrequencyOutOfRange`). `feed_pcm` throttles full-window AMDF to every 4th feed (~20 ms); `amdf_hz` early-prunes on a provably-unbeatable partial sum. Mic drain is 512 B/tick (16 kHz stereo produces ~320 B/5 ms). Micro-bench: `cargo test --release -p passport-core --test perf -- --ignored --nocapture`.
- Quality: `cargo test -p passport-core` then `cargo build -p passport-os --release --target riscv32imc-unknown-none-elf`.
