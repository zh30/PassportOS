26 · 掉线与恢复（状态迁移，无专属屏）

关联丢失 → worker 发 Disconnected → 状态栏 Wi-Fi 标记消失、 wifi 状态记 fail dropped。

已存开放网络：自动重连 ≤ REJOIN_MAX=3 次（后台静默，不走 UI）； 加密网/超上限：停留断线态，等用户回 19 手动重连。

用户主动 disconnect/forget 不触发自动重连。

35 · 权限边界 = 资源互斥（无弹窗设计）

本 OS 无权限对话框；Wi-Fi / BLE / 音频 DMA 同一时刻只能占一路，由系统仲裁：

· 开 Wi-Fi（18）时 BLE 在广播 → 自动停 BLE
· 开 BLE（27）时 Wi-Fi 已连 → 自动断开 Wi-Fi
· 进 Tune/Boo（07/08）时 radio 开着 → 先 radio off 再开 I2S
· mic 占用中播 beep → 静音填充（不出声）

36 射频初始化失败（降级）

触发
wifi worker init 失败（内存不足等）
行为
worker 不死：后续 scan 回空列表（→20）、join 回 fail radio——用户可见可重试，不静默吞命令

界面层无感；等下次操作重试或重启

37 · 麦克风链路自恢复（内部机制）

RX 用 sig_loopback 跟随 TX 时钟；TX 常喂（静音/PCM）防 underrun 停钟。

看门狗：mic 开启后 500ms 无 PCM 字节 → 自动重启 DMA 读， 记 [mic] rx stall #n；关闭时打印累计 bytes/stalls。

UI 表现：Tun​​e 显示无变化（hz 保持 0/上次值），恢复后继续出数。

37 I2S RX stall 看门狗

表现
用户无感；日志可查 [mic] rx stall

38 · 凭据/存储异常 → 回首次流程

KV 页 POSW 记录 CRC 校验失败 / 从未保存 / forget 后：
→ wifi_saved=None，无自动重连，Wi-Fi 界面无 forget 行，走 18→19 首次连接流程。

时钟未设：KV 无 time → 状态栏显示默认时钟；time HH:MM 或菜单设置后写回 KV。
